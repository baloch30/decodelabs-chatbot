# DecodeLabs Rule-Based Chatbot

A simple rule-based AI chatbot built in Python as Project 1 of my AI internship at Decode Labs.

## Features
- Continuous input loop using `while True`
- Input sanitization (`.lower().strip()`)
- Dictionary-based knowledge base with 5+ intents
- Fallback response for unknown inputs
- Clean exit with `bye` or `exit`

## How to run
python chatbot.py
